This post introduces container attribute-based rules for AWS Network Firewall, enabling security teams to create firewall policies based on Kubernetes attributes like pod names and namespaces rather than ephemeral IP addresses. The feature provides dynamic rule updates for containerized workloads on Amazon EKS and ECS with enriched logging for security visibility.
